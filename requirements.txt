# ── A note on pinning ──────────────────────────────────────────────────────
# These are exact versions this project was tested against end-to-end:
# training ran cleanly, all 33 tests passed, and the dashboard booted and
# every page rendered — all from a fresh virtual environment. Pinned
# deliberately: the shipped models/*.pkl are pickled scikit-learn/XGBoost
# objects, and loading them with a different library version than they
# were trained with can print warnings or, on a bigger version jump, fail
# outright. If you need newer versions for another reason, the simplest
# fix is to re-run `python train.py` afterward to regenerate the models
# against whatever versions you actually have installed.
